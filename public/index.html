Independent fan-inspired project, not affiliated with Marvel or connected to Instinct.

Without a backend, this page runs only local commands. With the supplied backend, users can sign in, keep conversation memory and submit tracked tasks. Female ElevenLabs voice requires separate configuration; otherwise the browser voice is used. General AI and tool planning require a separately configured model provider and may cost money.

"Friday: Godspeed" is a public fun greeting only. It does not unlock accounts, memory or permissions. No full device access, account automation, unrestricted web crawling or code execution. The workspace is limited to a per-user server folder. Web access is administrator-allowlisted. Speech recognition may send audio to your browser provider. Voice needs HTTPS and mic permission; text works as a fallback.

The local conversation resets on reload. Backend tasks and memory remain until deleted according to your deployment. Do not enter secrets in commands. Only connect a backend you control and trust.
